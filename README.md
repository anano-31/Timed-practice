# Timed Practice

A log of timed, focused practice sessions across different programming languages
and tools I'm learning. Each session follows the same format: a fixed time limit,
a set of exercises to get through, and an honest record of what went right and
what didn't — mistakes included.

## Why timed sessions

The time limit forces real problem-solving under mild pressure instead of slow,
comfortable pattern-matching. The goal isn't to finish everything — it's to see
how much I can reason through correctly in a fixed window, and to track how that
improves over time.

As I start practicing new languages or tools, I'll add a new top-level folder
following the same pattern.

## How each session is scored

Every session README reports three numbers plus a difficulty level:

- **Level** — rough difficulty of the exercises attempted (e.g. beginner, intermediate)
- **Correct** — fully correct on the first pass
- **Had issues** — right idea, wrong execution (syntax slip, self-corrected, etc.)
- **Incorrect** — wrong logic or wrong result

Raw scores aren't the main point. What matters more is *what* went wrong —
whether it was a careless mistake or a genuine gap in understanding — since
that's what determines what to drill next.
